# 🌊 深海花园 — 自动化操作工具

基于 **MSS 截图 + OpenCV 模板匹配 + pynput 鼠标控制** 的游戏自动化脚本集。

## ✨ 功能一览

| 脚本 | 功能 | 操作方式 |
|------|------|---------|
| `01-种花.py` | 种植花朵 | 选花种 → 长按花种 → 实时扫描空地 → 拖动种植 |
| `02-浇水.py` | 浇水 | 找缺水花 → 点第一朵 → 长按浇水按钮 → 实时扫描拖动 |
| `03-收获.py` | 收获花朵 | 找成熟花 → 点第一朵 → 长按收获按钮 → 遍历拖动 |
| `04-加速.py` | 加速生长 | 找需加速花 → 免费加速可选 → 长按加速按钮 → 遍历拖动 |
| `05-铲除.py` | 铲除花朵 | 找花 → 点第一朵 → 长按铲除按钮 → 实时扫描拖动 |
| `06-顾客订单.py` | 处理顾客订单 | 循环3次，处理已制作好/缺货/需要制作的订单 |
| `07-居民订单.py` | 居民订单提交 | 点牌子进入 → 连点提交按钮 → 关闭 |
| `08-偷花.py` | 偷花摘取 | 一次扫描 → 按顺序点击摘取按钮 |

---

## 🚀 快速开始

### 环境要求

```bash
pip install pynput pillow mss opencv-python-headless numpy pypinyin
```

### 运行脚本

所有脚本在项目根目录下运行：

```bash
python 任务/01-种花.py
python 任务/02-浇水.py
python 任务/03-收获.py
python 任务/04-加速.py
python 任务/05-铲除.py
python 任务/06-顾客订单.py
python 任务/07-居民订单.py
python 任务/08-偷花.py
```

> **停止运行**：任何时候按键盘 **Esc** 键即可安全停止，会自动松开鼠标。

## 📸 素材采集与更换

### 采集方法

使用任意截图工具（微信截图 `Alt+A`、PixPin、系统截图 `Win+Shift+S`）：

1. **打开游戏**，让目标元素显示在屏幕上
2. **截图**，剪裁出目标元素的最小矩形范围
3. **保存 PNG** 到对应的 `素材/` 目录下

### 命名规范

文件名任意，但必须为 `.png` 格式。`素材/` 下的文件夹编号与脚本编号对应。

### 采集技巧

- **越小越准**：截图尽量只包含目标元素，不要包含背景
- **同一元素截一张**：同一种花/按钮只需截一次
- **多种花各截一张**：不同种类的成熟花、花种各截一张，脚本会自动用多张模板匹配
- **测试识别**：截图后可以先跑脚本测试能否识别到

## ⚙️ 配置说明

文件：`配置/设置.txt`

```ini
拖动间隔 = 0.1          # 拖动速度（0.05极速 ~ 0.5慢速）
点击偏移 = 中心          # 点击偏移方向（中心/左上角/右下角/下端）
偏移像素 = 15           # 偏移像素量
最大上限 = 50            # 每次最多处理数量（0=不限制）
居民订单提交尝试次数 = 8  # 居民订单每轮最多提交数
种花最大翻页次数 = 5     # 种花最多翻几页
```

## 🧠 工作原理

```
MSS 截图（毫秒级全屏截图）
    ↓
OpenCV matchTemplate（模板匹配，找所有匹配位置）
    ↓
pynput 鼠标控制（点击、长按、拖动）
```

脚本识别到模板图片后返回的是图片的**中心坐标**，不是左上角。配置中的 `点击偏移` 可在此基础上偏移位置。按 **Esc** 随时停止。
